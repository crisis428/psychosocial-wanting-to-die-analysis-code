# Input templates

These CSV files contain **column headers only**. No participant records are included.

- `primary_analysis_template.csv` — primary regression, machine-learning, SHAP, and network input structure.
- `phq8_sensitivity_template.csv` — adds `phq8_total` for the depressive-symptom sensitivity analysis.
- `categorical_sensitivity_template.csv` — adds the 4-category marital-status variable used in categorical-coding sensitivity analysis.

Actual study data cannot be included in this repository. See `docs/DATA_AVAILABILITY.md`.
