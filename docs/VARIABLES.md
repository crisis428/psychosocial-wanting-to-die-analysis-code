# Analytic variable dictionary

This file describes the variable names expected by the public code. It does not contain participant data.

| Variable | Role / coding used in analysis |
|---|---|
| `participant_id` | Local participant identifier used only inside the restricted analytic environment. |
| `py_thoughts_wanting_to_die` | Primary binary outcome: self-reported past-year thoughts of wanting to die (0 = no, 1 = yes). |
| `age_years` | Age in years. Regression reports age per 10-year increase. |
| `sex_female` | Binary sex indicator used in the analytic files (0 = male, 1 = female). |
| `married_current` | Current marriage indicator (0 = not currently married, 1 = currently married). |
| `marital_status_4cat` | Four-category marital-status coding used only in the categorical sensitivity analysis; married is the reference category in the regression code. |
| `employed_corrected` | Corrected current-work status (0 = not currently working, 1 = currently working). |
| `living_alone` | Living arrangement (0 = living with others, 1 = living alone). |
| `poor_subjective_physical_health` | Four-level subjective physical-health item; higher values indicate poorer health. |
| `poor_subjective_mental_health` | Four-level subjective mental-health item; higher values indicate poorer health. |
| `gad7_total` | GAD-7 total score. |
| `pss14_total` | PSS-14 total score. Regression reports effects per 1 SD. |
| `low_self_esteem_score` | Self-esteem score oriented so higher values indicate lower self-esteem. Regression reports effects per 1 SD. |
| `low_sense_of_belonging` | Four-level item oriented so higher values indicate lower sense of belonging. |
| `low_perceived_social_equality` | Four-level item oriented so higher values indicate lower perceived social equality. |
| `low_social_trust` | Four-level item oriented so higher values indicate lower social trust. |
| `phq8_total` | PHQ-8 total score, used only in the depressive-symptom sensitivity analysis. |

Exact questionnaire wording and response labels are reported in the manuscript supplement rather than reproduced here.
