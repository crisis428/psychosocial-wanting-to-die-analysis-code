# 데이터 공개 안내

이 저장소에는 참여자 수준 자료를 포함하지 않습니다. 연구 데이터는 IRB 승인 범위와 기관 데이터 거버넌스 제한에 따라 외부 반출 또는 공개 공유가 허용되지 않습니다. 대신 `data_templates/`에 열 이름만 포함된 빈 입력 템플릿을 제공합니다.

내부 ML checkpoint에는 참여자별 outcome, 예측확률, 식별자/행 인덱스 및 train/test split index가 포함되어 있으므로 공개하지 않습니다. `verification/`에는 참여자 수준 정보가 없는 집계 검증 결과만 포함합니다.
