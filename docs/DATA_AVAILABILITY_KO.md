# 데이터 공개 안내

IRB 승인 데이터 이용기간이 종료되었으며, 연구의 윤리 승인 조건과 기관 규정에 따라 참여자 수준 자료의 외부 반출과 공유는 허용되지 않습니다. 승인된 이용기간이 끝나면 해당 자료를 삭제해야 합니다.

이 저장소에는 분석 코드, 열 이름만 있는 입력 템플릿, 소프트웨어 정보, 계산 설정 및 집계 결과만 포함합니다. 참여자별 자료, 결과변수, 예측확률, 식별자, 분할 인덱스 및 checkpoint는 공개하거나 요청에 따라 제공하지 않습니다.

다른 자료에 코드를 적용할 때는 이용 권한이 있는 자료만 사용해야 합니다. 입력 구조는 `data_templates/`와 `docs/VARIABLES.md`에 있습니다. 소프트웨어 테스트는 합성자료를 사용하며 원 연구자료를 필요로 하지 않습니다.
